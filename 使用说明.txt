﻿拓竹打印监控 · 使用说明
========================================

【这是什么】
  一个 Windows 桌面小工具，给拓竹（Bambu Lab）3D 打印机用。
  打印完成、需要换料、机器报错时，在你电脑上弹通知 + 响提示音。
  不用一直盯着打印机，也不依赖手机。


【怎么装】
  不需要安装，也不需要装 Python。
  1) 把压缩包解压到任意目录（建议 D:\工具\拓竹打印监控 这类路径，
     不要只放在压缩包里双击，也不要放进 C:\Program Files）
  2) 双击「拓竹打印监控.exe」
  3) 如果 Windows 弹出「已保护你的电脑」：
     点「更多信息」→「仍要运行」（程序没有数字签名，属于正常现象）


【第一次配置（必须做，约 1 分钟）】
  程序第一次打开会自动弹出「设置」窗口。
  1) 点「自动搜索打印机」
     → 会扫局域网 1~3 秒，出现结果后点一下，IP 和序列号自动填好
  2) 访问码：
     点「从 Bambu Studio 导入访问码」，或手动输入
     访问码在打印机屏幕上：设置 → 网络 → 访问码（8 位）
  3) 点「测试连接」→ 显示连接成功 → 点「保存」

  ※ 如果搜不到打印机：确认打印机和电脑连的是同一个 WiFi。
    还不行就在设置里手动填 IP（打印机屏幕：设置 → 网络）。


【打印机和电脑不在同一个网络？】
  比如打印机连手机热点、电脑连家里 WiFi —— 局域网就连不上了。
  改用云端：
  1) 设置 → 跨网络（云端）→ 勾选
  2) 点「登录 / 更换账号」
  3) 填拓竹账号（手机号或邮箱）→ 点「发送验证码」
  4) 把收到的 6 位数字填进「验证码」→ 点「登录」
  5) 登录成功后会自动选中你账号下绑定的打印机

  ※ 程序没有扫码登录（拓竹官方没开放这个接口），只能用验证码或密码。


【我打开 Bambu Studio，监控会自己弹出来吗？】
  会 —— 但有一个前提：监控程序得先「在运行」。

  原理：监控程序每 2 秒看一眼 Bambu Studio 有没有启动，
        发现它启动了就把自己弹到前台并自动连接。
        如果监控程序根本没开，就没人去看，自然不会弹。

  所以有两种用法，选一种：

  做法 A（推荐，什么都不用管）
    设置里勾选「开机自动启动」+「启动时最小化」→ 保存
    之后：开机 → 监控静默待在托盘（任务栏 ^ 里）
          → 你双击 Bambu Studio → 监控自己弹出来并连上
    ※ 第一次打开程序时这两项已经默认勾好了，直接点「保存」即可。

  做法 B（不想让它开机常驻）
    用本文件夹里的「让拓竹启动时带上监控.bat」：
    右键它 → 发送到 → 桌面快捷方式，以后用这个图标开 Bambu Studio，
    监控会跟着一起起来。

    注意：同文件夹的 launcher.ps1 要一起保留（它才是真正干活的脚本），
          两个文件不能拆开，也不能单独改名。

    它会按顺序自动找 Bambu Studio：
      1) 注册表里登记的安装位置
      2) C:\Program Files\Bambu Studio 等常见位置
      3) 开始菜单里的快捷方式
    找不到会弹窗提示，告诉你怎样手动指定路径。
    想先确认它能不能找到，可以在这个文件夹打开 PowerShell 运行：
      powershell -ExecutionPolicy Bypass -File launcher.ps1 -DryRun

  ⚠️ 说明：Windows 没有「程序 A 启动时自动运行程序 B」的通用开关，
     所以「打开 Studio 自动弹出」必须靠上面两种方式之一来保证监控在跑。


【开机自动启动】
  设置 → 勾选「开机自动启动」+「启动时最小化」
  勾选后程序会把自己写进「注册表 → 当前用户 → 启动项」。
  注意：
  - 记录的是当前 exe 的完整路径。
  - 如果之后把文件夹移动位置或改名，自启会失效；
    但下次手动打开程序时，它会自动把注册表路径改回正确位置（本版本已支持），
    保险起见也可以重新进设置勾一次。
  - 这个设置只对当前 Windows 用户生效，不需要管理员权限。


【关窗口 ≠ 退出】
  点右上角 X 只是收进「系统托盘」（任务栏右下角）。
  Windows 默认把新图标收进 ^ 折叠区，第一次用请点开 ^，
  把图标拖到任务栏上，以后就一直可见。
  想真正退出：右键托盘图标 → 退出程序。


【会提醒你什么】
  ✅ 打印完成（可以用弹窗/声音/系统通知，可分别开关）
  ❌ 打印失败
  ⏸ 打印暂停 —— 会写明原因（断料、堵头、温度异常、AMS 掉线…）和处理建议
  🎨 换料
  ⚠ 机器故障（HMS 编码 + 哪个模块 + 怎么排查）
  📡 打印机失联（断连超过 120 秒）

  你手动取消打印不算故障，不会报警。


【几个已知限制（老实说明）】
  - AMS 湿度：打印机只给 1~5 的干燥度档位，不是百分比。
  - AMS 温度：A1 mini / AMS Lite 没有这个传感器，显示「—」。
  - AMS 余料：只有带 RFID 的原厂料卷才准，其他显示「余量未知」。
  - 不支持摄像头，不支持多台打印机同时监控。


【常见问题】
  Q: 收不到通知？
  A: Windows 设置 → 系统 → 通知，确认已打开，并关掉「专注助手」。
     程序里点「试听/测试通知」可以立刻验证。

  Q: 提示「跨网段」/ 连不上？
  A: 打印机和电脑不在同一网络。要么让打印机连同一个 WiFi，要么改用云端。

  Q: 杀毒软件报毒？
  A: 用 PyInstaller 打包的程序常被误报，可加入信任列表。

  Q: 双击没反应？
  A: 看看托盘里有没有图标（可能已经启动过了）；程序只允许运行一个实例。

  Q: 提示音没声音？
  A: 检查系统音量和音量合成器里本程序的音量，确认设置里勾了「提示音」。


【隐私】
  配置文件在 %APPDATA%\BambuMonitor\config.json
  里面保存了你的打印机访问码和拓竹登录令牌 —— 不要把这个文件发给别人。
  程序不会向任何第三方上传数据，也不做使用统计。


【卸载】
  1) 先关掉程序（托盘右键 → 退出程序）
  2) 设置里取消「开机自动启动」（或者手动删掉注册表启动项 BambuMonitor）
  3) 直接删除整个文件夹
  4) 想彻底清干净：再删除 %APPDATA%\BambuMonitor 文件夹
